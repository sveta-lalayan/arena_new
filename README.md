# Arena 2.0

> Для айти-специалиста, который будет оценивать масштабируемость и план
> перехода к веб-приложению — см. `HANDOFF.md`.

Телеграм-бот: геймификация + AI-персонажи для языковой практики.
Всё, что было связано с разговорным клубом (расписание, подписки, напоминания,
multitenant, broadcast, host-режим), убрано. Осталось два блока:

- **Профиль и баллы** (`gamification.py`, `database.py`) — баллы начисляются за
  каждый пройденный раунд диалога + бонус за завершение + бонус за высокий результат.
  Игровой уровень (Новичок → Легенда) растёт вместе с баллами. Есть достижения.
- **AI-арена** (`ai.py`, `handlers/arena.py`) — пользователь выбирает язык,
  уровень CEFR, тему и персонажа с ярким характером (CEO, журналист, профессор,
  HR, философ, "адвокат дьявола"), ведёт с ним диалог и в конце получает разбор
  ответов (аргументация, словарный запас, грамматика, беглость).

## ⚠️ Перед запуском — обязательно

Старый токен бота был закоммичен в открытый репозиторий в виде текста прямо в
`config.py`. Это значит, что он скомпрометирован.

1. Зайди к **@BotFather** → `/mybots` → выбери бота → **Bot Settings → API Token → Revoke**.
2. Новый токен положи только в `.env` (см. `.env.example`) — этот файл в `.gitignore`
   и никогда не должен попадать в git.
3. Если репозиторий уже публичный — стоит почистить историю git (например,
   `git filter-repo`), т.к. старый токен останется виден в старых коммитах, даже
   если удалить файл сейчас.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# заполни BOT_TOKEN, YANDEX_API_KEY, YANDEX_FOLDER_ID
```

## Запуск

```bash
python bot.py
```

При первом запуске автоматически создаётся файл БД (`arena2.db`,
путь задаётся в `.env`) со схемой: `users`, `game_sessions`, `achievements`.

## Структура проекта

```
bot.py            — сборка приложения, регистрация хендлеров
config.py         — переменные окружения
game_data.py       — языки, уровни CEFR, персонажи, бейджи
database.py        — SQLite: профиль, история игр, достижения
gamification.py    — баллы, игровые уровни, достижения, текст профиля
ai.py               — Yandex GPT: реплики персонажей и анализ ответов
handlers/
  start.py          — /start, главное меню
  profile.py        — /profile, /achievements
  arena.py           — весь игровой поток (выбор языка → уровень → тема →
                        персонаж → диалог → фидбэк)
```

## Как настроить баллы/уровни/бейджи

Всё в одном месте — `gamification.py`:

- `PLAYER_LEVELS` — пороги баллов для игровых уровней.
- `POINTS_PER_ROUND`, `COMPLETION_BONUS`, `HIGH_SCORE_BONUS` — формула начисления баллов.
- `check_and_unlock_achievements()` — условия разблокировки бейджей (сами бейджи
  описаны в `game_data.py` → `BADGES`).
